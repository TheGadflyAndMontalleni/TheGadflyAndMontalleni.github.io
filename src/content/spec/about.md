# 关于我 / About

你好，我是 **RIME_SUN**。这里是我的技术笔记本——学到什么就记什么，隔一段时间回头修订。

## 这里放什么

- **编程**：语言、库、框架，以及程序性能优化
- **算法**：数据结构、复杂度分析、解题时的思路
- **系统**：操作系统、网络、计算机体系结构
- **站点说明**：这个博客本身的用法与维护方式

写笔记只有一条原则：**只写自己真正弄懂的部分**。写不清楚的地方，多半是还没懂。

## 关于本站

本站使用 [Astro](https://astro.build/) 构建，主题为 [Firefly](https://github.com/CuteLeaf/Firefly)（基于 [Fuwari](https://github.com/saicaca/fuwari) 二次开发），构建产物是纯静态文件，托管在 nginx 上。

- **笔记源码**：每篇笔记都是 `src/content/posts/` 下的 Markdown 文件，该目录也可以直接作为 Obsidian 仓库打开
- **全文搜索**：由 Pagefind 在构建时生成索引，无需后端
- **订阅**：站内提供 [/rss/](/rss/) 订阅

想了解这个站是怎么写的、怎么发布的，可以先看那篇 [[notes/how-to-write|写作速查]]。
